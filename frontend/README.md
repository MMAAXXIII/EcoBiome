# EcoBiome Web Dashboard

Prototype d’interface web pour EcoBiome.

## Installation

Installez les dépendances dans le dossier `frontend` :

```bash
cd frontend
npm install
```

## Exécution

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Notes

Ce dossier contient un prototype de dashboard Vite + React + TypeScript + Tailwind. Il reproduit la structure observée dans la preview Bolt : tableau de bord, milieux aquatiques, diagnostics, journal scientifique et galerie média.
