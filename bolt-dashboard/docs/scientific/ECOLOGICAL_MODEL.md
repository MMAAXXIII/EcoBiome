# Ecological Model

> Modèle écologique de référence d'EcoBiome.

---

# Objectif

Le modèle écologique définit comment EcoBiome représente les êtres vivants, leurs besoins, leurs interactions et leur évolution dans le temps.

Contrairement à une base de données classique, EcoBiome ne décrit pas uniquement des espèces.

Il décrit également :

- leurs fonctions écologiques ;
- leurs préférences environnementales ;
- leurs interactions ;
- leurs performances biologiques ;
- leurs capacités d'adaptation.

---

# Philosophie

Une espèce n'est pas une simple fiche descriptive.

C'est un organisme vivant interagissant avec :

- son environnement ;
- les autres organismes ;
- les ressources ;
- les cycles biogéochimiques.

EcoBiome modélise ces interactions plutôt que de simplement vérifier des compatibilités.

---

# Les cinq niveaux du modèle écologique

EcoBiome représente le vivant à cinq niveaux.

## Niveau 1 — Individu

Exemples :

- un médaka ;
- une crevette Amano ;
- une plante.

Chaque individu possède :

- un âge ;
- une taille ;
- une biomasse ;
- un état de santé ;
- un sexe (si applicable) ;
- une génétique ;
- une énergie disponible.

---

## Niveau 2 — Population

Une population regroupe les individus d'une même espèce.

Elle possède notamment :

- effectif ;
- structure d'âge ;
- diversité génétique ;
- natalité ;
- mortalité.

---

## Niveau 3 — Espèce

Une espèce définit les caractéristiques biologiques communes.

Elle contient notamment :

- préférences écologiques ;
- comportements ;
- reproduction ;
- alimentation ;
- physiologie.

---

## Niveau 4 — Niche écologique

La niche écologique décrit le rôle fonctionnel de l'espèce.

Exemples :

- producteur primaire ;
- détritivore ;
- prédateur ;
- filtreur ;
- décomposeur ;
- consommateur de biofilm.

Plusieurs espèces peuvent partager une même niche.

---

## Niveau 5 — Écosystème

L'écosystème correspond à l'ensemble :

- des espèces ;
- des interactions ;
- des ressources ;
- des flux de matière ;
- des flux d'énergie.

---

# Les préférences écologiques

Chaque espèce possède des préférences.

Exemple :

Température

- létale minimale
- survie minimale
- acceptable minimale
- optimale
- acceptable maximale
- survie maximale
- létale maximale

Même principe pour :

- pH
- GH
- KH
- conductivité
- oxygène
- profondeur
- lumière
- courant
- salinité
- pression
- humidité (pour les futurs terrariums)

---

# Les courbes de performance

Les performances biologiques ne sont pas binaires.

Chaque paramètre possède une courbe de réponse.

Exemple :

- croissance
- reproduction
- activité
- alimentation
- immunité

sont toutes influencées différemment par la température.

Le moteur calcule un indice de performance compris entre 0 et 100 %.

---

# Les interactions écologiques

EcoBiome distingue plusieurs types d'interactions.

## Coopération

Exemple :

plantes ↔ bactéries

---

## Compétition

Exemple :

deux espèces consommant la même ressource.

---

## Prédation

Relation prédateur / proie.

---

## Mutualisme

Les deux organismes bénéficient de l'interaction.

---

## Commensalisme

Un organisme bénéficie de l'autre sans effet notable.

---

## Parasitisme

Un organisme bénéficie au détriment de l'autre.

---

## Décomposition

Transformation de matière organique en éléments minéraux.

---

# Les ressources

Les ressources peuvent être :

- lumière ;
- oxygène ;
- nourriture ;
- carbone ;
- azote ;
- phosphore ;
- potassium ;
- espace ;
- abris.

Chaque ressource peut devenir limitante.

---

# Les facteurs limitants

La croissance d'un organisme est limitée par le facteur le plus contraignant.

EcoBiome applique ce principe à l'ensemble des ressources.

---

# Les niches écologiques

Chaque espèce est décrite par sa niche.

Une niche comprend notamment :

- alimentation ;
- habitat ;
- profondeur ;
- activité ;
- mobilité ;
- stratégie de reproduction ;
- stratégie énergétique ;
- rôle trophique.

La niche permet de comparer plusieurs espèces sans se limiter à leur taxonomie.

---

# Les indicateurs biologiques

EcoBiome calcule notamment :

- indice de santé ;
- indice de stress ;
- indice de croissance ;
- indice reproducteur ;
- espérance de vie estimée ;
- taux de mortalité ;
- résilience.

---

# Les fonctions écologiques

Chaque espèce apporte une ou plusieurs fonctions.

Exemples :

- production d'oxygène ;
- consommation d'algues ;
- recyclage des déchets ;
- consommation de biofilm ;
- filtration ;
- brassage du substrat.

Le moteur cherche à équilibrer ces fonctions.

---

# Résilience

La résilience représente la capacité d'un écosystème à retrouver un équilibre après une perturbation.

Elle dépend notamment :

- de la biodiversité ;
- de la redondance fonctionnelle ;
- de la diversité génétique ;
- de la stabilité des ressources.

---

# Objectif d'EcoBiome

EcoBiome ne cherche pas uniquement à vérifier si deux espèces sont compatibles.

Il cherche à comprendre si l'ensemble de l'écosystème est :

- stable ;
- résilient ;
- durable ;
- équilibré.

Les recommandations sont produites à l'échelle de l'écosystème, et non d'une seule espèce.

---

# Vision à long terme

À terme, EcoBiome devra être capable de représenter des réseaux écologiques complexes dans lesquels chaque organisme est relié aux autres par des flux de matière, d'énergie et d'information.

Le moteur devra être capable d'expliquer ces relations et de proposer des améliorations argumentées, en tenant compte des objectifs de l'utilisateur et des incertitudes des données disponibles.
