# Feuille de route de long terme

La feuille de route privilégie les contrats et la stabilité avant
l'infrastructure distribuée.

## Phase 0 — Socle de stabilité

**État : largement réalisé sur la branche de consolidation.**

- package canonique ;
- imports reproductibles ;
- sécurité de base ;
- données locales hors Git ;
- tests et pré-push ;
- documentation structurée.

## Phase 1 — Documentation et contrats

- index documentaire ;
- principes directeurs ;
- statuts explicites ;
- ADR du métamodèle ;
- registre des sources ;
- formats et compatibilité.

## Phase 2 — Métamodèle minimal

Trois profils pilotes :

- aquarium d'eau douce ;
- potager ou serre ;
- mare extérieure.

Objets minimaux :

- systèmes ;
- structures ;
- zones ;
- contenance ;
- participation ;
- flux ;
- révision immuable.

## Phase 3 — Provenance et confiance

- statut épistémique ;
- incertitude ;
- licence et source ;
- agrégation privée/communautaire ;
- critères de validation.

## Phase 4 — Expérience utilisateur quotidienne

- saisie rapide ;
- chronologie unifiée ;
- populations et organismes ;
- équipements et consommables ;
- rappels ;
- export et sauvegarde ;
- budget.

## Phase 5 — Occupation, médias et capteurs

- sites d'observation ;
- empreinte de mesure ;
- trajectoires ;
- interactions ;
- confidentialité spatiale ;
- ingestion multimodale.

## Phase 6 — Énergie et résilience

- mesures et estimations ;
- budgets par zone et système ;
- pertes et rendements ;
- autonomie et délestage ;
- recommandations sans compromettre la sécurité biologique.

## Phase 7 — Concepteur de biotopes

- contraintes absolues ;
- compatibilité biologique ;
- bilans ;
- résilience ;
- mise en service progressive ;
- comparaison prévu/réel.

## Phase 8 — EcoBiome@home

- worker local ;
- protocole de jobs ;
- quotas et mode sûr ;
- stockage hot/cold ;
- validation de résultats ;
- cloud optionnel.

## Phase 9 — Apprentissage contrôlé

- comparaison de projets ;
- connaissance agrégée consentie ;
- expériences reproductibles ;
- mise à jour gouvernée des modèles ;
- aucune promotion automatique d'un témoignage en vérité universelle.
