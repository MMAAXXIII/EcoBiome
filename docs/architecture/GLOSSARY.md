# Glossaire EcoBiome

| Terme | Définition |
|---|---|
| Artefact | Fichier ou résultat produit par une étape : transcription, analyse, média, cache ou rapport. |
| Control Plane | API, interface et orchestration des jobs, droits et quotas. |
| Data Plane | Collecte, normalisation, analyse et gestion des artefacts. |
| Compute Plane | Ressources CPU/GPU exécutant les tâches. |
| Cloud Plane | Stockage partagé, index, droits et rétention. |
| Worker Plane | Machine volontaire exécutant des tâches sous quotas. |
| Écosystème | Ensemble réel étudié, éventuellement composé de plusieurs systèmes et structures. |
| Système | Ensemble fonctionnel ou processus. |
| Structure | Objet physique pouvant contenir des structures ou zones. |
| Zone | Espace environnemental observable. |
| Contenance | Relation physique directe et acyclique. |
| Participation | Relation fonctionnelle d'une entité à un ou plusieurs systèmes. |
| Flux | Route orientée entre une source et une destination. |
| Révision | Vue complète et immuable d'une topologie. |
| Validité temporelle | Période pendant laquelle une relation ou réalité est tenue pour valable. |
| Observation | Preuve datée avec provenance et qualité. |
| Estimation | Valeur calculée à partir d'un modèle et d'hypothèses. |
| Simulation | Résultat d'un scénario, non présenté comme une mesure. |
| Occupation spatio-temporelle | Présence d'un organisme dans un lieu et une période, avec incertitude possible. |
| DLQ | File des tâches ayant échoué de façon persistante. |
| Hot storage | Stockage rapide pour calculs et intermédiaires, typiquement NVMe. |
| Cold storage | Stockage économique pour archives, typiquement HDD. |
| Local-first | Fonctionnement local disponible sans cloud obligatoire. |
