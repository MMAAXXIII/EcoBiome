# EcoBiome Module Catalog

> Catalogue officiel des modules du projet EcoBiome.

Ce document recense tous les modules scientifiques, techniques et fonctionnels du moteur.

Chaque module possède :

- un objectif ;
- une priorité ;
- un état d'avancement ;
- des dépendances ;
- un niveau de complexité destiné à l'utilisateur ;
- un niveau de maturité scientifique.

---

# Légende

## Priorité

| Niveau | Signification |
|---------|---------------|
| P0 | Indispensable au fonctionnement du moteur |
| P1 | Première version utilisable |
| P2 | Fonctionnalité importante |
| P3 | Fonctionnalité avancée |
| P4 | Recherche / expérimental |

## Maturité

| Niveau | Signification |
|---------|---------------|
| Planned | Prévu |
| Prototype | Première implémentation |
| Implemented | Fonctionnel |
| Validated | Validé scientifiquement |
| Stable | Stable |

## Niveau utilisateur

- Débutant
- Intermédiaire
- Avancé
- Recherche
