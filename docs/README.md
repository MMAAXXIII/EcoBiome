# Documentation EcoBiome

Ce répertoire distingue quatre niveaux documentaires :

1. **Vision** — mission, horizon de long terme et principes de gouvernance.
2. **Architecture** — frontières techniques, plans distribués et modèle de données.
3. **Conception scientifique** — décisions de domaine, hypothèses et questions ouvertes.
4. **Références** — textes inter-IA conservés sans les présenter comme du code déjà implémenté.

## Statuts utilisés

| Statut | Sens |
|---|---|
| `IMPLEMENTED` | Présent et validé dans le dépôt courant. |
| `PROPOSED` | Cible ou décision proposée, non encore implémentée. |
| `EXPERIMENTAL` | Prototype ou piste nécessitant une validation. |
| `OPEN` | Question non arbitrée. |
| `DEFERRED` | Élément volontairement reporté. |
| `REFERENCE` | Source conservée pour mémoire, sans autorisation d'implémentation implicite. |

Une proposition documentaire n'autorise jamais, à elle seule, une modification
du code, l'ajout d'une dépendance, un déploiement cloud ou une automatisation
agissant sur un écosystème réel.
