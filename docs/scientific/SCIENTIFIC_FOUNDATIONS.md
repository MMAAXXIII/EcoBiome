# Scientific Foundations

## Mission

EcoBiome est un moteur de raisonnement scientifique destiné à comprendre, expliquer, simuler et optimiser des écosystèmes.

Le moteur doit être capable de raisonner avec des informations complètes comme incomplètes, tout en expliquant clairement ses hypothèses, ses limites et son niveau de confiance.

---

# Concepts fondamentaux

## 1. Scientific Variable

Une variable scientifique représente une grandeur du monde réel.

Exemples :

- Température de l'eau
- pH
- Volume d'eau
- Conductivité
- Oxygène dissous
- Biomasse végétale

Une variable ne possède pas de valeur.

Elle décrit uniquement ce qui peut être observé, estimé ou simulé.

---

## 2. Value

Une valeur représente l'état d'une variable à un instant donné.

Exemples :

Température = 22.4 °C

pH = 7.3

Volume = 235 L

---

## 3. Measurement

Une mesure est une valeur obtenue par observation.

Une mesure possède notamment :

- une date
- une méthode
- un instrument
- une précision
- un opérateur
- une source

---

## 4. Estimated Value

Une valeur estimée est déduite à partir d'informations incomplètes.

Elle doit toujours être accompagnée :

- d'un niveau de confiance
- des hypothèses utilisées
- des informations manquantes

---

## 5. Simulated Value

Une valeur simulée est produite par un modèle scientifique.

Elle doit pouvoir expliquer :

- les variables utilisées
- les processus impliqués
- les hypothèses
- les limites du modèle

---

## 6. Scientific Relation

Une relation décrit l'influence d'une variable sur une autre.

Exemple :

Volume d'eau

↓

augmente

↓

Inertie thermique

Une relation possède :

- une direction
- une intensité
- un domaine de validité
- un niveau de preuve scientifique

---

## 7. Scientific Process

Un processus décrit une transformation.

Exemples :

- Photosynthèse
- Nitrification
- Respiration
- Évaporation
- Convection
- Diffusion

Les processus utilisent plusieurs variables.

---

## 8. Scientific Law

Une loi représente une règle fondamentale.

Exemples :

- Conservation de la masse
- Thermodynamique
- Diffusion
- Gravitation

Les lois sont indépendantes d'un écosystème particulier.

---

## 9. Scientific Model

Un modèle combine plusieurs lois, processus et relations afin de représenter un phénomène.

Exemple :

Modèle de nitrification

↓

Lois chimiques

+

Croissance bactérienne

+

Température

---

## 10. Evidence

Chaque connaissance scientifique doit pouvoir être justifiée.

Une preuve peut provenir :

- d'une publication scientifique
- d'un ouvrage de référence
- d'une norme
- d'une expérience reproductible
- d'une observation documentée

Chaque preuve possède un niveau de confiance.

---

# Principes

Le moteur ne doit jamais répondre :

"Je ne sais pas."

Il doit répondre :

- voici ce que je sais ;
- voici ce que je suppose ;
- voici ce qui manque ;
- voici le niveau de confiance ;
- voici comment améliorer la précision.

---

# Philosophie

EcoBiome sépare toujours :

- les données
- les connaissances
- les modèles
- les algorithmes

Le moteur logiciel ne contient pas la science.

La science est décrite dans la base de connaissances.

Le moteur applique cette connaissance.
