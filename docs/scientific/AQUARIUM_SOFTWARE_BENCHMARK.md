# Benchmark fonctionnel des logiciels d'aquariophilie

**Statut :** source d'inspiration ; aucune copie de contenu ou d'interface.

## Besoins de base observés

- gestion de plusieurs systèmes ;
- paramètres, historique et graphiques ;
- tâches et maintenance ;
- inventaire biologique et technique ;
- photos et journal ;
- compatibilité et fiches d'espèces ;
- calculatrices et planification ;
- budget ;
- export et sauvegarde ;
- capteurs et automatisation.

## Socle à ne pas négliger

La sophistication scientifique ne remplace pas :

- la saisie rapide ;
- une chronologie unifiée ;
- le suivi par organisme ;
- le suivi par équipement ;
- des seuils contextualisés ;
- le fonctionnement local.

## Différenciation EcoBiome

- modèle multi-écosystème ;
- raisonnement causal explicable ;
- provenance et confiance ;
- topologie versionnée ;
- occupation spatio-temporelle ;
- énergie et résilience ;
- apprentissage contrôlé ;
- conception de biotopes.

## Risques

- devenir un simple carnet d'aquarium ;
- créer un silo par bac ;
- utiliser une liste fixe de paramètres ;
- fournir un assistant opaque ;
- stocker une base d'espèces sans provenance ;
- rendre le cloud obligatoire ;
- automatiser sans état sûr ;
- recopier des textes, bases, écrans ou identités visuelles.

## Architecture produit suggérée

```text
Usage quotidien
→ Analyse
→ Raisonnement
→ Ingénierie écologique
→ Automatisation contrôlée
```
