# Modes d'écosystème et connaissance

**Statut :** synthèse du dossier de conception 001.

## Décision structurante

Ne pas construire une hiérarchie rigide de « modes ». Distinguer :

- le **profil d'écosystème**, qui décrit ce qui est observé ou conçu ;
- le **mode de travail**, qui décrit l'action demandée.

Modes possibles : conception, installation, surveillance, diagnostic,
maintenance, expérimentation, amélioration, restauration, documentation et
comparaison.

## Dimensions composables

- domaine ;
- type de système ;
- enveloppe ;
- biotope et localisation ;
- finalité ;
- organismes ;
- niveau de contrôle ;
- échelle ;
- géométrie ;
- zones ;
- flux.

## Zones internes

Un système n'est pas uniforme. Une serre, un paludarium ou un aquarium peuvent
avoir plusieurs zones avec leurs propres paramètres, organismes, capteurs,
contraintes et flux.

## Connaissance

Trois niveaux restent séparés :

1. mémoire privée ;
2. connaissance communautaire agrégée et consentie ;
3. référence validée et sourcée.

Une plage biologique conserve contexte, stade de vie, durée d'exposition,
niveau de preuve et source.

## Conception assistée

Le moteur futur procède par couches :

1. contraintes absolues ;
2. compatibilité biologique ;
3. bilans ;
4. résilience ;
5. mise en service progressive ;
6. comparaison prévu/réel.

## Questions ouvertes
