===============================================================
3. ARCHITECTURE ECOBIOME@HOME (CALCUL VOLONTAIRE)
===============================================================

Concept :
- chaque utilisateur devient un worker volontaire
- CPU/GPU/NVMe/HDD mis à disposition
- tâches distribuées
- résultats renvoyés au cloud
- logiciel léger pour tous

Étapes :
- prototype worker local
- prototype scheduler FastAPI
- file de tâches (pending / processing / done / failed / DLQ)
- validation des résultats (hash, double calcul)

===============================================================
4. SÉPARATION NVME / HDD
===============================================================

NVMe (hot storage) :
- artefacts temporaires
- caches ML
- segments audio
- fichiers intermédiaires

HDD (cold storage) :
- archives
- datasets
- vidéos originales
- logs historiques

Créer un module ecobiome.storage pour gérer automatiquement les chemins.

===============================================================
5. EXPORT CLOUD

Module à créer :
